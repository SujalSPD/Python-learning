# Useful Git Commands

## 1. Check Git Status
Shows the current state of the repository.

git status


## 2. Initialize a Git Repository
Creates a new Git repository in the current folder.

git init


## 3. Add Files
Adds a specific file to the staging area.

git add filename.py

Adds all changed files:

git add .


## 4. Commit Changes
Saves the staged changes with a message.

git commit -m "Your commit message"


## 5. Push Changes to GitHub
Uploads committed changes to the remote GitHub repository.

git push


## 6. Pull Changes from GitHub
Downloads the latest changes from the remote repository.

git pull


## 7. Clone a Repository
Downloads an existing GitHub repository to your computer.

git clone repository_url


## 8. View Commit History
Shows previous commits.

git log

Short version:

git log --oneline


## 9. Check Remote Repository
Shows the GitHub repository connected to your local repository.

git remote -v


## 10. Create a New Branch
Creates a new branch.

git branch branch_name


## 11. Switch Branch
Switches to another branch.

git checkout branch_name

Modern command:

git switch branch_name


## 12. Create and Switch to a New Branch
Creates a new branch and switches to it.

git switch -c branch_name


## 13. See All Branches
Shows all local branches.

git branch


## 14. Delete a Branch
Deletes a local branch.

git branch -d branch_name


## 15. Unstage a File
Removes a file from the staging area without deleting it.

git restore --staged filename.py


## 16. Discard Changes
Discards changes made to a file since the last commit.

git restore filename.py


## 17. See Differences
Shows the changes made to files.

git diff


## 18. Rename a File
Renames a file and tells Git about the change.

git mv old_name.py new_name.py


## 19. Remove a File
Removes a file from the repository.

git rm filename.py


## 20. Git Workflow

The basic workflow for uploading changes to GitHub is:

git status
git add .
git commit -m "Describe your changes"
git push

# Remember

Git = Version control system

GitHub = Online platform for hosting Git repositories

git add = Stage changes

git commit = Save changes locally

git push = Upload changes to GitHub

git pull = Download changes from GitHub
